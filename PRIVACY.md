# Privacy Policy for Diffs

**Last Updated:** 2026-01-15

## Local Comparison

Diffs compares selected content in your browser. File contents and pasted text are not uploaded for comparison. There are no accounts, advertisements, or analytics in the application.

## Application Requests

The hosting provider receives ordinary requests for the application and its assets and may retain connection logs. Run the app on localhost to serve it from your own machine.

## Browser Storage

Sessions remain in the current page. Reloading discards this workspace.

## File Access and Exports

Diffs reads content you select or paste. It does not change your original files. Requested exports may contain source text, filenames, or fingerprints.

## Source and Questions

Inspect the [source](https://github.com/qtremors/diffs) or report questions through [GitHub Issues](https://github.com/qtremors/diffs/issues).
